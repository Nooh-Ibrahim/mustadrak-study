# group-a-study-hub
Group A Study Hub — Interactive study materials · A Mustadrak project

**الموقع:** https://nooh-ibrahim.github.io/group-a-study-hub/

## الموقع ده إيه
ملفات مذاكرة Group A (كلية الذكاء الاصطناعي، جامعة الدلتا) في لينك واحد ثابت.
- بيشتغل **من غير نت** بعد أول فتحة، ويتضاف للشاشة الرئيسية كأنه تطبيق.
- تقدّم كل طالب (الإجابات وعلامات «مهم») محفوظ على جهازه هو بس، والموقع مابيلمسهوش.

## الملفات
| الملف | فيه إيه |
|---|---|
| `index.html` | الصفحة الرئيسية: كارت لكل مادة |
| `courses/` | ملفات المواد (HTML)، بتتنسخ زي ما هي من البناء |
| `pdfs/` | نسخ الطباعة |
| `icons/` و `fonts/` | الأيقونات والختم والخط |
| `manifest.webmanifest` | بيانات التطبيق (الاسم والأيقونات) |
| `sw.js` | الشغل من غير نت (Service Worker) |
| `.nojekyll` | عشان GitHub Pages ينشر الملفات زي ما هي |

## إزاي يتحدّث
1. انسخ ملف المادة الجديد (HTML و PDF) مكان القديم في `courses/` و `pdfs/`، **بنفس الاسم**.
2. لو فيه مادة جديدة: ضيف ملفاتها في قايمة `FILES` في `sw.js`، وكارتها في `index.html`.
3. زوّد `VERSION` بواحد في `sw.js`، وزوّد «إصدار الموقع» و `hub-version` في `index.html`.
4. ارفع على `main`، والموقع بيتحدّث لوحده في دقيقة أو اتنين.

الصفحات بتتجاب من النت الأول، فالتحديث بيوصل أول ما الطالب يفتح بالنت، ومن غير نت بيفتح آخر نسخة اتحفظت.
**ماتغيّرش أسماء ملفات المواد**: اللينكات اللي الطلبة حافظينها هتبوظ.
